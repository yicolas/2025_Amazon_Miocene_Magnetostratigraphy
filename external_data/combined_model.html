Sea level equivalent

SLE = Vice × ρiceAocean × ρsw − Vbelow SLAocean

Linear inundation reach

xreach = ΔSL × Lhtarget = ΔSLSlinear

Concave (piecewise) inundation

xreach = max { d : e(d) ≤ ΔSL }

Where e(d) is the piecewise-linear elevation profile interpolated between control points. Sea penetrates to the farthest point where river bed elevation ≤ sea level.
